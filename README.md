# Amazon ML Challenge 2026 - Business Entity Resolution

End-to-end pipeline for the **Amazon ML Challenge 2026 - Business Entity Resolution** task.

## Problem
Given three sources of business entity records (Source 1, Source 2, Source 3), find which records in Source 2 and Source 3 refer to the same real-world business as each record in Source 1.

- Source 1: ~2.2M records (train) / ~1.7M (test)
- Source 2: ~5M records
- Source 3: ~5.3M records
- Countries: US, India (train); US, India, France (test)

## Project Structure

```
src/
    load_data.py     - Load all 7 TSV files, print shapes/columns/stats
    normalize.py     - Vectorized text cleaning: lowercase, diacritics,
                       abbreviation expansion, punctuation removal
    blocking.py      - Inverted-index blocking: generate candidate pairs
                       and evaluate recall vs. ground truth
output/
    candidate_pairs.tsv   - Generated by blocking.py (not committed)
```

## Blocking Strategy

Four complementary blocking keys per record (all on normalized text):

| Key | Tag | Description |
|-----|-----|-------------|
| country + name[:5] | `c5:` | High-precision same-country prefix |
| country + first token (>=5 chars) | `ct:` | Catches suffix/punctuation variation |
| name[:6] (no country) | `p6:` | Cross-country bridge |
| sorted 2 significant tokens | `st:` | Handles word-order transpositions |
| country + address[:6] *(fallback)* | `ca:` | Recovers non-Latin script names (Hindi) |

## Normalization Pipeline

```
raw text
  -> Unicode NFKD (strip diacritics, fallback for Devanagari)
  -> lowercase
  -> abbreviation expansion  (Inc->Incorporated, Ltd->Limited, Rd->Road ...)
  -> remove punctuation [^a-z0-9\s]
  -> collapse whitespace
```
