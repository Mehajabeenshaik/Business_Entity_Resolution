# Amazon ML Challenge 2026 – Business Entity Resolution

End-to-end pipeline for the **Amazon ML Challenge 2026 – Business Entity Resolution** task.

## Problem
Given three sources of business entity records (Source 1, Source 2, Source 3), find which records in Source 2 and Source 3 refer to the same real-world business as each record in Source 1.

- Source 1 is the deduplicated reference set.
- A Source 1 entity may match zero, one, or many records from Source 2 / Source 3.
- Scoring metric: **macro F0.5** (precision weighted higher than recall).

## Repository Structure

```
src/
    load_data.py        - Load TSV files, environment-variable path configuration
    normalize.py        - Vectorized text cleaning, diacritic handling, non-Latin support
    blocking.py         - Inverted-index multi-key blocking, outputs candidate pairs
    features.py         - Pairwise feature extraction using RapidFuzz & string similarities
    train.py            - CatBoost + baseline training, group validation, F0.5 threshold selection
    evaluate.py         - Full evaluation on training ground truth & blocking recall ceiling
    predict.py          - Score test candidates and output matching_results.tsv
    validate_output.py  - Strict submission file validator
    main.py             - Pipeline orchestrator
artifacts/
    model/              - Saved models, config, and selected threshold
    features/           - Feature column definitions
    validation/         - Validation metrics, summary reports, and feature importance
output/
    candidate_pairs.tsv  - Candidate entity pairs (generated by blocking.py)
    matching_results.tsv - Final predictions (generated by predict.py)
```

## Setup

```bash
pip install -r requirements.txt
```

Set the dataset root path environment variable (optional if dataset is in default location):
```bash
export AML_DATASET_ROOT="/path/to/student_resource/dataset"
```

## Running the Pipeline

```bash
# 1. Run blocking on train set
python -m src.blocking

# 2. Train the CatBoost model and find optimal threshold
python -m src.train

# 3. Evaluate model on train ground truth
python -m src.evaluate

# 4. Generate candidate pairs on test set (overwrites candidate_pairs.tsv)
python -m src.blocking test

# 5. Generate predictions for test set
python -m src.predict

# 6. Validate output submission files
python -m src.validate_output
```
